# TikTok Media Downloader Bot

Асинхронный Telegram-бот для автоматизированной загрузки видеоконтента из TikTok. Проект включает систему многоуровневого кэширования медиафайлов и интеграцию с реляционной базой данных PostgreSQL.

## Функциональные возможности

* **Асинхронная архитектура:** Построение на базе `aiogram 3.x`, обеспечивающее параллельную обработку входящих запросов без блокировки Event Loop.
* **Валидация доступа:** Механизм автоматической проверки подписки пользователя на целевой канал перед выполнением целевого действия.
* **Управление сессиями БД:** Использование асинхронного пула соединений (`asyncpg`) для оптимизации работы с базой данных под нагрузкой.
* **Изоляция тяжелых процессов:** Выполнение функций загрузки видео в отдельном потоке исполнения (`run_in_executor`) для сохранения отзывчивости интерфейса бота.

## Технологический стек

* **Runtime:** Python 3.10+
* **Framework:** aiogram 3.x
* **Database:** PostgreSQL
* **Database Driver:** asyncpg
* **Engine:** yt-dlp
* **Environment:** python-dotenv

## Конфигурация

Для работы бота необходимо создать файл `.env` в корневой директории проекта и указать следующие параметры:

```env
BOT_TOKEN=your_bot_token
CHANNEL_ID=@your_channel
DB_NAME=postgres
DB_USER=your_user
DB_PASSWORD=your_password
DB_HOST=your_host
